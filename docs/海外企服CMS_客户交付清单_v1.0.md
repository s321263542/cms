### 3.3 改内容会发生什么（八种操作，全部有记录）

| 你点的按钮 | 官网会怎样 |
|---|---|
| 保存草稿 | **官网完全不变**，卡片上标"已发布 · 有新改动"提醒还没发布 |
| 提交审核 | 官网不变，稿件进入审核队列 |
| 审核通过 · 发布 | **官网立即更新**，同时自动存一份历史版本 |
| 退回草稿 | 官网不变，退回去继续改 |
| 下线 | 这条内容立刻从官网消失（数据还在，随时能再上线） |
| 重新上线 | 恢复展示 |
| 撤销改动 | 草稿丢弃，官网从头到尾没动过 |
| 回滚到历史版本 | 出事故时用，一键把这条内容退回旧版本，立即生效 |

### 3.4 三个贴心功能

- **草稿预览**：内容还没发布，但想让领导先看看效果？生成一个带有效期的预览链接发给他，只有打开这个链接的人能看到草稿，页面上方有"预览模式"横幅，普通客户永远看不到。
- **改稿对比**：发布之前，系统会把"现在网上的版本"和"准备发布的版本"逐条对比，改了什么一目了然，避免误发。
- **历史记录**：每次发布都会存一份完整快照，随时能查"这条内容上个月长什么样"，并能一键退回。
